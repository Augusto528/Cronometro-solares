# Cronômetro Solares

A web application for recording race times and tracking events in solar boat competitions.

## Overview

The project provides a digital timing interface designed around the needs of solar boat events. It supports competition and individual timing workflows, records race events, and allows timing data to be exported as a text file.

## Features

- Competition and individual timing modes.
- Recording of timing events such as laps, buoys/points, and finish-line events.
- Support for multiple teams, including Arariboia, Solares, and Solaris.
- Export of recorded timing data to a `.txt` file.
- Web interface built with React and TypeScript.

The available options and workflow may depend on the current version deployed.

## Technology Stack

- React
- TypeScript
- Vite

## Getting Started

### Requirements

- Node.js and npm.

### Install dependencies

From the application directory (`cronometro-barcos` in this repository), run:

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Vite will print the local URL in the terminal.

### Build for production

```bash
npm run build
```

If the scripts differ in the current `package.json`, follow the scripts defined there.
